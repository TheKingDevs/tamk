# Versionamento

**Versão atual:** `1.0.0`

## Esquema

```
YYYY.MAJOR.MINOR[-SUFIXO]

1.0.0
├── 2026: Ano de release
│   └── 3: Major (mudanças significativas)
│       └── 0: Minor (features)
│           └── -HMR: Sufixo (HMR = Hot Module Replacement)
```

## Sufixos

| Sufixo | Significado |
| :--- | :--- |
| `-HMR` | Release com suporte a Hot Module Replacement |
| `-alpha` | Versão instável para testes |
| `-beta` | Versão de teste com features congeladas |
| `-rc.N` | Release candidate |
